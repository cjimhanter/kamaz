# Камаз. Щебень

Для агента: сначала `AGENTS.md` в этом репозитории. Там продукт, стек, запреты и что ещё не сделано.

Сайт заявок на щебень под ключ. v0: лендинг, форма, уведомление в VK и MAX, SQLite.

## Запуск

```bash
cp .env.example .env
# заполни SITE_PHONE, затем VK_* и/или MAX_*
uv sync
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Открой http://127.0.0.1:8000

Без токенов заявка всё равно пишется в `data/leads.db`. Telegram не подключаем в v0.

## Куда приходит заявка

Нужен хотя бы один канал. Оба сразу тоже можно.

### VK

1. Создай сообщество (можно черновик «Камаз щебень»).
2. Включи сообщения сообщества.
3. Управление → Работа с API → создай ключ с правом сообщений.
4. Отец один раз пишет в сообщения сообщества со своей страницы.
5. В `.env`: `VK_ACCESS_TOKEN` и `VK_PEER_ID` (числовой id страницы отца, или `peer_id` беседы).

Без шага 4 VK не даст сообществу писать человеку первым.

### MAX

1. Создай бота в [MAX для бизнеса](https://dev.max.ru/) / мини-приложении «MAX для бизнеса».
2. Возьми токен: Чат-боты → расширенные настройки, или команда «Получить токен».
3. Отец пишет боту из MAX.
4. В `.env`: `MAX_BOT_TOKEN` и `MAX_USER_ID` (или `MAX_CHAT_ID` для чата).

Запросы идут на `https://platform-api2.max.ru`, токен только в заголовке `Authorization`.
